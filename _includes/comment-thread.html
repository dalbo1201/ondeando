{%- comment -%} Renderiza, recursivamente, as respostas de um comentário. Parâmetros: comments = lista completa de comentários da página parent = id do comentário pai (0 = comentários raiz) depth = nível atual (começa em 1) max_depth = nível máximo permitido (ex.: 5) ATENÇÃO: no Jekyll, "assign" dentro de include é GLOBAL e é sobrescrito pelas chamadas recursivas. Por isso nenhuma variável assign é usada DEPOIS da chamada recursiva (o include recursivo é a última coisa do bloco). {%- endcomment -%} {% assign children = include.comments | where: "parent_id", include.parent %} {% for c in children %} {% assign is_author = false %} {% if c.name == site.author %}{% assign is_author = true %}{% endif %}
